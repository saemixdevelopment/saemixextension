This folder contains the examples and simulations included in the paper "Extending the saemix package for R to fit non Gaussian outcomes" (title TBD).

The code requires the following packages to be installed:
- saemix (version 3.5 or higher)
- npde (version 3.5 or higher)
- ggplot2
- gridExtra

The files generating the figures and tables for the paper also require the following packages:
- xtable
- survival (for the TTE model)

All paths are relative to the root folder (paperSaemix3) and by default figures generated in the scripts will be saved in subfolder figs.

### Case-studies script files

The case-studies are detailed in Rstudio notebooks (containing explanations and code chunks). The code chunks are also included in R scripts which can be run independently. To run the examples, you can either:
- open each notebook (.Rmd) and execute the code in Rstudio
ex: saemix3_tteModel.Rmd contains the code used to run the time-to-event models
or 
- source each script file separately 
ex: source("saemix3_tteModel.R") to run the time-to-event models
or
- source all the models by running test_codeFiles.R
ex: source("test_codeFiles.R")

### Results included in the paper

The figures and tables for the case-studies in the paper can be reproduced by running the corresponding R scripts:
- binary and categorical data: paper_figCategorical.R (calls saemix3_categoricalModel.R)
- count data: paper_figCount.R (calls saemix3_countModel.R)
- survival data: paper_figTTE.R (calls saemix3_tteModel.R)

Each of these files first calls the case-studies scripts to run all the corresponding models (please be patient, this can take a while). This will recreate the figures and tables in the paper, saving the figures in the figs folder (overwriting the current figures).

The results from the simulation study are stored in the folder discreteEval. The corresponding figures and tables can be regenerated by executing the script paper_simulBinary.R from the root folder.

Bootstrap runs (R scripts) and results used to obtain confidence intervals for parameter estimates are located in the folder bootstrapRes. They can be run using specific R scripts, which will then store the results in the corresponding .res files. These files contain toggles which can be used to run only certain models.

### Additional code

The results related to the covariate selection for the lung dataset (TTE case-study) and the knee dataset (categorical data) can be found in the folder covselect along with the bootstraps applied to the final covariate model for the TTE model.
